# Security reporting

For a sensitive concern about Predator, an Aether service, or private data, use [Aether's contact channel](https://aethersystems.net/contact?intent=general&product=site_wide&cta=footer_updates_contact) and identify the report as **Predator security**.

Include the affected component, observed behavior, potential impact, and a safe summary of the evidence. Keep credentials, personal data, live target details, and exploit material out of public issues, discussions, and pull requests.

Non-sensitive corrections to public documentation or evidence can use the [issue tracker](https://github.com/AetherAI3/Predator/issues/new/choose).

The [Predator safety model](SAFETY.md) describes the required research boundaries and their implementation status. Public documentation and training examples do not grant permission to test Aether infrastructure or third-party systems.

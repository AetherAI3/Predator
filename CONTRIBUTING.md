# Contributing to the Predator showcase

This repository welcomes improvements to public documentation, research explanations, evidence indexes, and visual assets. The Predator CLI and operator engines are private; [apply for research access](https://aethersystems.net/contact?intent=general&product=site_wide&cta=footer_updates_contact) for work in those areas.

## Choose the right place

| You want to… | Start here |
| :--- | :--- |
| Correct a broken link, unclear explanation, or inaccurate public record | [Open a documentation issue](https://github.com/AetherAI3/Predator/issues/new/choose) or send a focused pull request |
| Ask about a study or suggest a future public demo | [Start a discussion](https://github.com/AetherAI3/Predator/discussions) |
| Report a sensitive security or privacy concern | Follow [SECURITY.md](SECURITY.md) |
| Explore the public results first | Read the [docs index](docs/README.md) |

## Make a useful contribution

Describe the page and reader problem, then propose the smallest clear change. Link the public source that supports factual corrections. Keep completion counts, dates, model/operator roles, and research limits consistent with the underlying record.

For HTB updates, follow the [collection guide](docs/htb/README.md). Distinguish an HTB-accepted result from a recovered candidate. Explain what a replay actually contains. Reviewed media changes require an updated hash and frame count in the manifest.

Before sending a pull request, check relative links, heading anchors, image descriptions, and the displayed layout. For research changes, verify the arithmetic against the linked public data and retain adverse or missing outcomes.

Keep credentials, private task bundles, live target details, VPN material, and unreleased evidence out of public issues and pull requests. Respect the [community guidelines](CODE_OF_CONDUCT.md).

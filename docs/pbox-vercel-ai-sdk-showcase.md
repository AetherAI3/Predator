# P-BOX: Vercel AI SDK local research replay

![Redacted Predator P-BOX replay](media/predator-pbox-vercel-ai-sdk-public.gif)

Predator's disposable Linux VM on VPS3 was used for an **authorized local security test of the Vercel AI SDK**. The last frame records a verified local result with **synthetic secret values redacted**. This is a visual showcase of the P-BOX workflow, not a technical reproduction or a claim of access to Vercel production systems.

Five desktop captures came from the actual VM session. They are presented as seven GIF frames, including two editorial highlights of the same already-redacted saved-value lines. The Predator viewer around them was rebuilt for the replay. FFmpeg applies strong blur and darkening to commands, endpoints, mechanism, repair steps, and other private terminal lines. The actual terminal, its prompts, the synthetic `saved [VALUE REDACTED]` lines, and the guest's completion line remain visible. No credential values, package versions, report details, or guest ID appear. The replay is not a continuous screen recording.

The full research record remains private. This page does not provide reproduction steps or disclose the issue.
